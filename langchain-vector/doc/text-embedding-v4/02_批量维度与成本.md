# 02 批量、维度与成本

本篇沿用 [01 的练习目录和密钥配置](01_配置与首次向量化.md)。同步 API 中 `text-embedding-v4` 支持 64、128、256、512、768、1024（默认）、1536、2048 维；单次最多 10 条，每条最长 8192 token。LangChain 的默认 `batchSize` 针对 OpenAI 服务设定，**不能直接套用到百炼**，这里显式设为 10。

## 指定维度并批量处理

保存为 `batch.ts`，执行 `npx tsx batch.ts`（需要密钥、网络，可能计费）：

```typescript
import { OpenAIEmbeddings } from "@langchain/openai";

const apiKey = process.env.DASHSCOPE_API_KEY;
if (!apiKey) throw new Error("请先设置 DASHSCOPE_API_KEY");

const dimensions = 512;
const embeddings = new OpenAIEmbeddings({
  apiKey,
  model: "text-embedding-v4",
  dimensions,
  batchSize: 10,
  configuration: { baseURL: process.env.DASHSCOPE_BASE_URL ?? "https://dashscope.aliyuncs.com/compatible-mode/v1" },
});

const texts = Array.from({ length: 12 }, (_, index) =>
  `政策片段 ${index + 1}：上海住宿报销以现行制度为准。`
);
const vectors = await embeddings.embedDocuments(texts);
if (vectors.length !== texts.length || vectors.some((vector) => vector.length !== dimensions)) {
  throw new Error("向量数量或维度与输入不一致");
}
console.log(`处理 ${texts.length} 条，向量维度 ${dimensions}`);
```

`batchSize: 10` 表示 LangChain 至多将 10 条文本放在一次请求里，不是免费的批处理或异步 Batch 优惠接口。12 条可能分成多次请求；失败后重试可能多次计费。控制单条长度、请求并发和限流，对 429 采取有限退避；不要无限重试。逐条 8192 token 上限按模型 token 计，不是 JS 字符数；切块时留出余量，遇到超长错误后缩小片段，不要静默截断重要条款。

## 选择维度

缩小维度可降低向量存储和检索开销，但未必保持同样的召回。建立表或索引前确定维度；文档和查询必须用同一模型、相同 `dimensions` 与相同预处理。不能只改变查询端维度，也不能把 512 维新向量直接追加到已有 1024 维列中。重建向量时保存模型名、维度、索引版本与数据来源，并用固定测试问题对比 `recall@k`。

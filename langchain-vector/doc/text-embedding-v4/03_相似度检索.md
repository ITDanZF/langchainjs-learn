# 03 相似度检索

向量是候选排序信号，不是“答案已被证明”的分数。这里直接使用 [01 的 `OpenAIEmbeddings`](01_配置与首次向量化.md) 得到文档和问题向量，在 TS 中计算余弦相似度，便于理解检索前后的数据流。示例文档与政策数字均为教学假设。

保存为 `search.ts` 并执行 `npx tsx search.ts`（需要有效密钥）：

```typescript
import { OpenAIEmbeddings } from "@langchain/openai";

const apiKey = process.env.DASHSCOPE_API_KEY;
if (!apiKey) throw new Error("请先设置 DASHSCOPE_API_KEY");
const embeddings = new OpenAIEmbeddings({
  apiKey,
  model: "text-embedding-v4",
  batchSize: 10,
  configuration: { baseURL: process.env.DASHSCOPE_BASE_URL ?? "https://dashscope.aliyuncs.com/compatible-mode/v1" },
});

const documents = [
  { id: "hotel", text: "P6 员工在上海出差，住宿上限为每晚 600 元。", source: "差旅制度/住宿" },
  { id: "train", text: "出差火车票凭有效票据报销。", source: "差旅制度/交通" },
  { id: "leave", text: "员工申请年假需要提前提交审批。", source: "休假制度" },
];
const question = "P6 去上海出差酒店每晚能报多少？";
const docVectors = await embeddings.embedDocuments(documents.map((doc) => doc.text));
const queryVector = await embeddings.embedQuery(question);

function cosine(left: number[], right: number[]): number {
  if (left.length !== right.length || left.length === 0) throw new Error("向量维度不匹配");
  const dot = left.reduce((sum, value, index) => sum + value * right[index], 0);
  const leftNorm = Math.hypot(...left);
  const rightNorm = Math.hypot(...right);
  if (leftNorm === 0 || rightNorm === 0) throw new Error("零向量不能计算余弦相似度");
  return dot / (leftNorm * rightNorm);
}

const ranked = documents.map((doc, index) => ({
  ...doc, score: cosine(queryVector, docVectors[index]),
})).sort((a, b) => b.score - a.score).slice(0, 2);
console.log(ranked.map(({ id, source, score }) => ({ id, source, score })));
```

这个实现在内存里遍历全部向量，只适合教学小样本。分数大小依赖模型、文本与度量方式，没有通用的“0.8 即正确”阈值。Top-2 可能包含不相关文档；应检查正确条款是否命中，再检查回答引用的条件和来源。使用 LanceDB 持久化向量及检索见下一篇。

下一篇：[04 LanceDB 持久化检索](04_LanceDB持久化检索.md)。

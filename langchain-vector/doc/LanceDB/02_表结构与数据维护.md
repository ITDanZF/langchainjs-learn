# 02 表结构与数据维护

## 从自动推断到显式模式

[上一课](01_本地入门与向量检索.md)从记录列表推断字段类型。实际项目建议显式规定向量维度、文本字段和可空性。Arrow 的 `FixedSizeList(2, ...)` 是**固定长度二维向量**，不是任意长度列表。

在完成 [01 的安装](01_本地入门与向量检索.md)后，再运行 `npm install apache-arrow`。保存以下代码为 `tables.ts`，运行 `npx tsx tables.ts`：

```typescript
import * as lancedb from "@lancedb/lancedb";
import { Field, FixedSizeList, Float32, Schema, Utf8 } from "apache-arrow";

const db = await lancedb.connect("./lancedb-demo");
const schema = new Schema([
    new Field("id", new Utf8(), false),
    new Field("text", new Utf8(), false),
    new Field("category", new Utf8(), false),
    new Field("vector", new FixedSizeList(2, new Field("item", new Float32(), true)), false),
]);
const table = await db.createEmptyTable("maintained_docs", schema, { mode: "overwrite" });
await table.add([
    { id: "a", text: "上海住宿标准", category: "travel", vector: [1.0, 0.0] },
    { id: "b", text: "年假申请流程", category: "leave", vector: [0.0, 1.0] },
]);

await table.update({ where: "id = 'a'", values: { text: "上海住宿标准每晚600元" } });
await table.delete("id = 'b'");
console.log("当前行数:", await table.countRows());
console.log(await table.query().select(["id", "text"]).limit(10).toArray());
console.log("表版本:", await table.version());
```

预计当前只有 `a` 一行。`delete` 使记录从查询结果中消失，但不是立刻销毁底层旧版本文件。`mode: "overwrite"` 只用于重跑教学示例，会覆盖同名表。

## 重新打开与避免重复写入

下一次运行时可以用 `await db.openTable("maintained_docs")` 打开已存在的表。`createTable` 的 `existOk` 在表存在时只是打开，不会自动追加提供的数据；需要追加时使用 `table.add([...])`。普通 `add` 不保证 `id` 唯一，重试写入时可能出现重复行；根据 `id` 做更新或插入可用 `mergeInsert`，也要先规划好输入键的去重规则。

```typescript
const existing = await db.openTable("maintained_docs");
const incoming = [{ id: "a", text: "上海住宿标准已调整", category: "travel", vector: [1.0, 0.0] }];
await existing.mergeInsert("id")
    .whenMatchedUpdateAll()
    .whenNotMatchedInsertAll()
    .execute(incoming);
```

上面片段沿用完整示例中的 `db` 和表，不可脱离它单独运行。若变更了文本而向量仍是旧 embedding，会造成检索信息不一致；真实项目应同时重新生成向量。

## 版本与清理

`await table.version()` 和 `await table.listVersions()` 可观察每次写入后的快照。可以 `await table.checkout(version)` 只读检查旧版，随后 `await table.checkoutLatest()` 返回可写最新版；**不要**把检视旧版和恢复旧版混为一谈。定期 `await table.optimize()` 可合并写入、更新已有索引并按保留策略清理旧文件；历史快照并非永久备份，清理前核对保留窗口。

# 01 本地入门与向量检索

## 本课目标

用一个本地目录保存数据库，写入带二维向量的记录，然后按距离查找相近记录。向量是教学用的手工数值，不代表真实文本 embedding。

## 环境

建议使用 Node.js 20+，在独立的练习目录中运行（无需改动仓库已有项目的依赖）：

```powershell
mkdir lancedb-ts-demo
cd lancedb-ts-demo
npm init -y
npm pkg set type=module
npm install @lancedb/lancedb
npm install -D tsx typescript @types/node
```

后续教程均在此目录运行；示例使用 `tsx` 运行 `.ts` 文件。

## 从建表到搜索

将下面完整代码保存为 `intro.ts` 并运行 `npx tsx intro.ts`。数据库路径相对于**运行命令的当前目录**；示例只覆盖教学表 `intro_docs`，已有的其他表不会被清除。

```typescript
import * as lancedb from "@lancedb/lancedb";

const db = await lancedb.connect("./lancedb-demo");
const rows = [
    { id: "hotel", text: "上海住宿标准每晚600元", category: "travel", vector: [1.0, 0.0] },
    { id: "train", text: "火车票凭票报销", category: "travel", vector: [0.8, 0.2] },
    { id: "leave", text: "年假申请提前提交", category: "leave", vector: [0.0, 1.0] },
];
const table = await db.createTable("intro_docs", rows, { mode: "overwrite" });

const queryVector = [0.9, 0.1];
const matches = await table.query().nearestTo(queryVector)
    .distanceType("l2")
    .select(["id", "text", "category", "_distance"])
    .limit(2)
    .toArray();
for (const match of matches) {
    console.log(match.id, match.text, match._distance);
}
```

预计前两条是 `hotel` 与 `train`，但两者到查询向量的理论距离相同，浮点舍入可能改变排名顺序。`_distance` 越小表示在 L2 距离下越接近，不是回答问题的置信度。这里没有建向量索引，搜索会扫描这些记录并得到精确近邻。

## 理解三个边界

1. 同一个向量列的所有记录必须使用同一维度；查询也必须提供同维向量。本例都是二维。
2. 真实文本检索需要同一个兼容的 embedding 模型分别生成文档与查询向量；不要把本例的手工向量当作中文语义搜索。
3. `{ mode: "overwrite" }` 会丢弃同名表原来的内容，只用于可重复的教学运行。生产写入应打开现有表后使用 `add`、`update` 等操作。

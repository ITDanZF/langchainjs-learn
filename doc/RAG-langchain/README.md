## 贯穿案例

教程使用一个虚构企业的报销助手作为例子：

- 员工 E001 的职级为 P6。
- 假定现行制度规定：P6 员工到上海出差，住宿上限为每晚 600 元。
- 报销单 R001 属于 E001，出差地为上海，共两晚、合计 1100 元，状态为审批中。

案例帮助比较不同范式的处理方式。金额、人物与制度均为教学假设，不是现实政策。

## 与前序学习的衔接

先读 [RAG 范式演进知识总结](../RAG-learn/01_RAG范式演进知识总结.md)，再进入这里的实现思路：

```text
朴素 RAG：建立检索与生成流程
高级 RAG：改善检索和上下文质量
模块化 RAG：组织与组合能力
Graph RAG：表示和检索知识关系
Agentic RAG：动态决定如何使用能力
```

这些范式可以组合。向量检索不专属于高级 RAG，多数据源不自动意味着 Agentic RAG，LangGraph 的流程图也不等于 Graph RAG 的知识图。
